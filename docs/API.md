# API contract

The authoritative current schema is [openapi.json](openapi.json), generated by `clinic-voice export-openapi`. Base path `/v1/tools`; all tools require `Authorization: Bearer cvt_<credential id>.<secret>`, issued by `clinic-voice credential issue`. The server resolves clinic identity from the active credential record. Malformed, unknown, wrong-secret, expired and revoked credentials all return the same 401 with `WWW-Authenticate: Bearer`. Unknown body fields, including `clinic_id` or patient fields, are rejected.

| Endpoint | Result | Current scope |
| --- | --- | --- |
| GET /health/live | 200 | Process liveness |
| GET /health/ready | 200 or 503 | DB/schema readiness; reports integrations not configured |
| POST /v1/tools/check-slots | 200 | Up to 3 local available timestamps, selected doctor/service/day |
| POST /v1/tools/reserve-slot | 202 | Atomic anonymous local reservation + pending calendar job |
| POST /v1/staff/login | 200 or 401 | Email + password → staff session token (12 h absolute lifetime) |
| POST /v1/staff/logout | 204 | Revoke the presented session |
| GET /v1/staff/me | 200 | Current staff user (id, email, role) |
| POST /v1/staff/me/password | 204 or 403 | Change own password; revokes the user's other sessions |
| GET /v1/staff/users | 200 | List the caller's clinic staff (owner, admin) |
| POST /v1/staff/users | 201 or 409 | Create staff in the caller's clinic with a temporary password (owner) |
| PATCH /v1/staff/users/{id} | 200, 404 or 409 | Change role or disable (owner); the last active owner cannot be removed |

Slot query: `doctor_id` UUID, `service_id` UUID, `day` ISO date. Valid dates are today through 90 days ahead in clinic timezone. Slots start on a duration grid from each configured opening time; end must fit inside the window. Past slots and local overlapping holds are excluded. Calendar external conflicts, holidays, buffers, and time-of-day filters are not implemented.

Reservation: `doctor_id`, `service_id`, offset-aware `starts_at`. Require `Idempotency-Key` (8–128 characters, letters/digits/dot/underscore/colon/hyphen). Same key/body replays appointment; same key/different body returns 409. Offset-equivalent timestamps hash identically. Invalid/missing authentication returns 401; unknown tenant catalog objects 404; validation 422; slot conflict 409. Database errors return a generic 503 without SQL details; retry the same logical action and idempotency key after recovery.

Response includes appointment ID, `pending_sync`, start/end, and cautious spoken text. This contract intentionally differs from the DOCX's `book-slot` request: no caller-supplied clinic phone, free-form doctor lookup, patient name/phone, or unconditional `CONFIRMED`. The future Bolna gateway must adapt trusted context into this API and complete identity verification before patient-specific changes.

## Staff authentication

Staff endpoints take `Authorization: Bearer cvs_<session id>.<secret>`. Tool credentials (`cvt_`) and staff sessions (`cvs_`) are not interchangeable. The staff user's clinic is the tenant for every staff call; bodies cannot carry `clinic_id`. Login failures for unknown, disabled, locked or wrong-password accounts return the same 401. Five consecutive failures lock an account for 15 minutes. Roles: `owner` manages staff; `admin` can list staff (and will manage clinic configuration next); `viewer` is read-only. Role and disable changes apply on the next request. Passwords are 12–256 characters; validation errors never echo them. Staff emails are globally unique, so creating an email already used by another clinic returns 409.

Cancel, reschedule, webhooks, clinic configuration CRUD, credential administration over HTTP, OAuth, provisioning, and provider administration endpoints are backlog items. No live Bolna tool payload is shipped as provider-validated JSON.
